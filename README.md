# TestApp1

## Purpose

This is a test app to dust off some rust and refamiliarize myself with C# and the testing suite
in preperation for a SDET I role. For the past while I have been making web apps primarily using
TypeScript, React, Firebase, Jest. But I really want this role so I figured I'd get a head start
by doing a small project to ensure I have the process down.

## Description

This app is a simple home owners insurance claims interface where a user can make, view, edit, and sort claims.
This is made using C#, MVC, Sweat, and probably a few tears. 

This app does not have authentication, multiusers, or a fancy stylized interface. This is because I want to knock
this out in a day and without the use of any AI assistance.

More information for the app reqirements can be found in [Requirements.md](./Requirements.md)
